
The first five-batch launch stopped before dataset construction. The installed
PyG `BaseTransform` requires subclasses to implement `forward`, while upstream
CATK implemented `__call__`. Commit `72d9685` updates both Waymo target
builders to the current PyG transform interface. Rerun the same smoke command
after applying that compatibility patch; this attempt did not exercise the GPU
and therefore produced no throughput, loss, or memory measurement.

The second launch constructed the 3.4M-parameter SMART-mini model and reached
the first training batch. It then exposed an AMP compatibility issue: the
preallocated agent-token tensor was float32 while token embeddings were
float16. Commits `9de9bc9` and `5a1479c` allocate the standard and ego-GMM
decoder tensors from the embedding output, preserving its device and dtype.
No optimizer step completed in this attempt (`global_step=0`).

The third launch completed all five training batches and two validation
batches on one GPU with 16-bit mixed precision. Lightning stopped normally at
one epoch, reporting `train/loss=7.59186`, `val_open/loss=7.57724`, and
`val_open/acc=0.00405`. The five training batches took about 2.3 seconds. This
passes the basic execution gate; checkpoint existence and reload remain to be
verified before the fixed BC run.
